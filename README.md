# KEAUTOS CARSTUDIO — demo

Site estático, sem comando de build. O `index.html` está diretamente na raiz do ZIP.

## Netlify Drop
Arraste o ZIP completo para a área de publicação. Confirme que a raiz publicada contém `index.html`, `styles.css`, `main.js` e `assets/`.

## GitHub + Netlify
Coloque estes ficheiros diretamente na raiz do repositório. No Netlify, deixe o comando de build em branco e publique a raiz (`.`). O `netlify.toml` já define essa pasta.

Antes de lançar como site oficial, confirme os serviços, os preços e a morada com a KEAUTOS.
